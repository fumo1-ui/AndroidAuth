# AndroidAuth
### Двухфакторная аутентификация Steam Guard для Android

- **Стек:** Kotlin 2.0, Jetpack Compose, Material Design 3
- **Назначение:** Мобильное управление сессиями Steam и импорт `.maFile`
- **Безопасность:** Полная автономность, нулевая телеметрия, локальное хранение

---

## 1. Проблематика и концепция

### Ограничения существующих решений:
- **Официальный клиент Steam:**
  - Не приспособлен для быстрого переключения между десятками учетных записей.
  - Требует регулярного повторного ввода учетных данных.
- **Steam Desktop Authenticator (SDA):**
  - Привязан исключительно к настольному компьютеру.
  - Делает невозможной оперативную мобильную авторизацию.

### Решение AndroidAuth:
Полноценный автономный мобильный клиент, поддерживающий прямое чтение файлов `.maFile` и генерацию кодов в реальном времени.

---

## 2. Алгоритм генерации кодов Steam TOTP

В отличие от стандартного алгоритма RFC 6238 (Google Authenticator), в Steam Guard применяются следующие особенности:

1. **Временной квант:** 30 секунд (`timestamp / 30`).
2. **Криптохеширование:** HMAC-SHA1 от 8-байтового представления времени по ключу `shared_secret` (декодированному из Base64).
3. **Динамическое смещение:** Извлечение 4 бит из 19-го байта хеша для вычисления 32-битного значения.
4. **Специализированный алфавит:**
   Преобразование значения в 5 символов по модулю 26 с использованием словаря:
   `23456789BCDFGHJKMNPQRTVWXY`

## 3. Синхронизация серверного времени

> Точность системного времени критически важна для валидности 2FA-кодов.

### Механизм синхронизации в AndroidAuth:
- Запрос к API: `https://api.steampowered.com/ITwoFactorService/QueryTime/v0001/`
- Определение сетевой задержки (Round-Trip Latency):
  `Latency = (T_end - T_start) / 2`
- Расчет и сохранение смещения часов:
  `Offset = (ServerTime + Latency) - LocalTime`
- Автоматическая коррекция таймера генерации токенов.

---

## 4. Обработка файлов .maFile

Парсер `SteamTotp.kt` обеспечивает устойчивость к различным типам входных данных:

- **Стандартный JSON SDA:** Поддержка базовых полей и вложенных объектов `Session`.
- **Регистронезависимый поиск:** `shared_secret`, `sharedSecret`, `steamid`, `account_name`.
- **Regex Fallback Parser:** Автоматическое извлечение секретов при наличии синтаксических ошибок в JSON.
- **Детекция шифрования:** Определение файлов с парольной защитой SDA (`encryption_iv`, `salt`) с выводом диагностического сообщения.
- **Чтение метаданных:** Извлечение привязанных почт, паролей, заметок и R-кодов.

---

## 5. Интеграция с Android OS

### Системные Intent Filters (`AndroidManifest.xml`):
- `android.intent.action.VIEW`:
  Прямое открытие файлов `.maFile` по клику в Files by Google, Total Commander и системном проводнике.
- `android.intent.action.SEND` и `SEND_MULTIPLE`:
  Пакетный импорт десятков файлов через системное меню «Поделиться».

### Пользовательский опыт (UX):
- Одно касание по карточке копирует 2FA-код в буфер обмена.
- Тактильный виброотклик (Haptic Feedback) на системном уровне.
- Полная локализация интерфейса (Русский / English).

---

## 6. Управление сессиями и интерфейс

- **Живой поиск:** Мгновенная фильтрация по логину, почте, SteamID64 или кастомному имени.
- **Избранное:** Закрепление основных учетных записей вверху списка.
- **Быстрый доступ к реквизитам:**
  - Логин и пароль аккаунта
  - Привязанный адрес электронной почты
  - R-Code (Revocation Code) для восстановления доступа
- **Пользовательские теги:** Присвоение произвольных названий для удобной навигации.

---

## 7. Модуль резервного копирования

### Возможности экспорта и импорта:
- **Полный бэкап:** Экспорт всей локальной базы сессий в единый JSON-файл для быстрого переноса на другое устройство.
- **Индивидуальный экспорт:** Сохранение выбранной учетной записи обратно в формат `.maFile`.
- **Безопасность миграции:** Возможность полной смены устройства без ручной повторной привязки аккаунтов через SDA.

## 9. Модель безопасности и приватность

### Ключевые гарантии безопасности:

1. **Песочница Android:**
   Все секретные данные хранятся в изолированном хранилище приложения (`Context.filesDir`). Доступ других программ заблокирован на уровне ядра Linux.
2. **Отсутствие аналитики:**
   В коде нет Firebase Analytics, Crashlytics, трекеров активности или рекламы.
3. **Чистый сетевой стек:**
   Единственный исходящий сетевой запрос — запрос публичного серверного времени Valve. Токены и секреты никогда не покидают устройство.
