Концепция и назначение проекта — почему создано приложение, решение проблемы привязки к ПК через Steam Desktop Authenticator (SDA) и неудобств официального клиента при работе с пулом аккаунтов.
Низкоуровневые технические особенности и криптография:
Математика генерации Steam Guard (отличие от стандартного RFC 6238 / Google Authenticator, 30-секундные временные окна, HMAC-SHA1, кастомный 26-символьный алфавит 23456789BCDFGHJKMNPQRTVWXY).
Алгоритм синхронизации серверного времени Valve (ITwoFactorService/QueryTime/v0001) с расчетом и компенсацией сетевой задержки (Round-Trip Latency).
Особенности парсинга .maFile: регистронезависимый поиск ключей, обработка вложенных структур сессий и отказоустойчивый Regex Fallback для восстановления поврежденных JSON.
Функционал:
Интеграция с Android Intent Filters (ACTION_VIEW, ACTION_SEND_MULTIPLE, прямая работа с проводниками вроде Files by Google).
Менеджмент аккаунтов (живая фильтрация, быстрый буфер обмена для логинов, паролей, 2FA и R-кодов, кастомные теги).
Модуль резервного копирования всей базы в один файл.
Архитектура и стек:
Подробная схема каталогов проекта (data, storage, totp, ui/components, theme).
Модель безопасности: изоляция данных в приватном каталоге песочницы Android, отсутствие телеметрии/аналитики и фоновых служб.
